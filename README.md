# MUSICA NEL TEMPIO

App Android per scalette musicali offline.

## Scarica l’app

**[Scarica APK per Android](https://github.com/silversil/Club-download/releases/latest/download/Musica-nel-Tempio.apk)**

Download pubblico, senza account GitHub. Richiede Android 8 o successivo.

1. Apri il link dal telefono o tablet Android.
2. Scarica e apri il file APK.
3. Se richiesto, autorizza il browser o l’app File all’installazione da questa sorgente.
4. Scegli **Installa** oppure **Aggiorna**. Non disinstallare la versione precedente per conservarne i dati.
5. Al primo avvio attendi la preparazione delle musiche. L’app e gli audio inclusi funzionano offline.

Il pacchetto è di circa 133 MB. Non è compatibile con iPhone.
